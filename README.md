# Влияние приложения для медитации на время засыпания
Учебный проект по постановке и проверке статистических гипотез.
Данные создаются заданной ячейкой ноутбука; после очистки анализ включает 44 парных наблюдения.
Выполнены задания 1–10 и возрастной бонус; подготовлены файлы проекта по заданию 11.
Проверено на Python 3.13.3; в Windows используйте короткий путь к проекту, например `C:\projects\mirera`, чтобы избежать ограничения длины пути при установке Jupyter.
Из папки проекта создайте окружение: `python -m venv .venv`.
В Windows установите зависимости: `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`.
Запустите `.\.venv\Scripts\python.exe -m jupyterlab`, откройте `solution.ipynb` и выполните Kernel → Restart Kernel and Run All Cells.
Среднее время снизилось на 3.11 мин (95% ДИ сокращения: 1.84–4.39 мин); без контрольной группы причинный вывод ограничен.
`solution.html` содержит сохранённые результаты для просмотра в браузере без установки Jupyter.
